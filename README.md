# LearnPlayWright2X

A small repository for learning Playwright using JavaScript.

## Structure

- `Chapter_01_Basics/`
  - `01_Basics.js` - Basic Playwright usage examples.
  - `02_JS_Commands.js` - JavaScript command examples for browser automation.

## Usage

1. Install Playwright and dependencies.
2. Run the examples from the `Chapter_01_Basics` folder.

## Notes

This repository is focused on Playwright basics and JavaScript automation commands.
